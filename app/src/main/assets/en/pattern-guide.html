Strategy guide

First moves

Start with the biggest clues. A run longer than half the line has to overlap itself: count that many cells in from the left, count the same number in from the right, and fill in where the two counts overlap. Lines whose clues, plus the single spaces forced between runs, nearly fill the whole width have very little slack — work those next. Fill what is certain, then change direction: the columns you just touched have new numbers to overlap as well.

Key patterns

Mark definite empties as you go; an empty cell is worth as much as a filled one because it cuts the space every nearby run can occupy. A gap shorter than the next clue it would have to hold is all empty. A completed run gets an empty cell capped on each end, which fixes where the neighbouring run can start. If the first cell of a line is filled, it begins the first run: count the full length in from the edge and cap the far end. Where two filled cells sit too far apart to belong to the same run, the space they cannot share splits the line into separate problems.

Common traps

Leaving out the mandatory space: exactly one empty cell, at least, sits between runs, and every length calculation has to include those spaces. Filling a cell because "a run must reach it" when two different runs both could is a guess wearing a costume. The dullest trap is solving rows only — alternate directions after every deduction, because each filled cell changes a column's arithmetic. And ignore the picture forming. The clues do not know what it is supposed to look like.
